# Nexora Backend

Nexora is a modern e-commerce platform for gadgets and electronic products.  
This repository contains the backend API of the Nexora e-commerce application, built with TypeScript, Express.js, MongoDB, and Mongoose.

## 🚀 Features

- User authentication and authorization
- Role-based access control
- Customer, Admin, and Vendor roles
- Product management
- Category management
- Order management
- User management
- Secure RESTful APIs
- MongoDB database integration
- Data validation using Mongoose
- Error handling and API response management
- Environment variable configuration

## 🛠️ Technologies Used

- **Node.js**
- **Express.js**
- **TypeScript**
- **MongoDB**
- **Mongoose**
- **JWT**
- **bcrypt**
- **dotenv**
